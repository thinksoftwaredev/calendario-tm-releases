# Calendario TecnoMarca — installatori

Qui ci sono **solo i pacchetti da installare**. Il codice sorgente sta in un repository privato: questo
è pubblico perché i PC dei pianificatori possano scaricare gli aggiornamenti **senza dover avere
credenziali**.

## Come si installa

Si scarica l'installatore più recente dalla pagina **Releases**, si apre e si segue la procedura.

L'installatore **non è firmato**: Windows mostra «Windows ha protetto il PC». Si preme
**«Ulteriori informazioni» → «Esegui comunque»**. È una scelta dichiarata, non un problema del file.

L'installazione è **per utente**: non servono i diritti di amministratore.

## Come si aggiorna

Da solo. Il programma controlla se c'è una versione più recente, la scarica in silenzio e la installa
**quando lo si chiude** — così non si riavvia mentre ci si sta lavorando dentro. Lo stato si vede nelle
**Impostazioni** del programma.

Disinstallare **non** cancella la configurazione né la password salvata.

## La guida completa

Per installare la prima volta servono anche tre script da lanciare sul database. La guida sta nel
repository del codice: `docs/installazione.md`.
